2026 年 10 月功能更新

这轮不只是多了一个模型。桌面端能帮你起草下一句话,手机能查看后台命令,CLI 也能直接找设置、保存常用提示词。先看自己用的那一端,不用把所有新名词一次学完。

先看清楚:更新的是哪一个端

你在用什么这次关注什么在哪里看步骤
桌面 AppTerra 模型、输入预测、模型迁移与速度档。桌面端怎么用
ChatGPT 手机 App / iOS文件引用、后台命令、跨电脑提及任务。手机接力
独立安装的 Codex CLI0.165.0,以及 /config、/presets、F9 静音。终端怎么升级
Security 插件用户0.1.32 的深度扫描报告收尾修复。怎么确认扫描完成
公司统一配置的账号模型提供商、Bedrock 和安全功能的条件。进阶功能边界

核对日期不等于发布日期。本次查到最新带日期记录是 10 月 27 日的 CLI 0.165.0;Terra 发布于 10 月 26 日。桌面端、CLI、iOS 和插件各有自己的版本,不要拿一个端的版本号去找另一个端的按钮。来源:官方更新日志。

桌面端:先试这两项就够了

GPT-6.1 Terra:看图、操作界面和写内容的新选择

10 月 26 日加入的 Terra 更侧重视觉理解、电脑操作和清楚的文字表达。比如拿一张网页截图让它找布局问题,或把一段技术说明改成客户看得懂的介绍。它不是“换上就什么都能做”,浏览器、文件和电脑操作仍要有相应工具与授权。

  1. 打开 Work 或 Codex,在模型选择器的 Advanced 中找 GPT-6.1 Terra。
  2. 先给一张不含隐私的截图,说清楚要检查的部分,要求只分析。
  3. 看它是否理解正确,再决定是否让它修改文件;修改后自己预览结果。

官方列出的套餐为 Plus、Pro、Business、Enterprise、Edu;它不是 Chat 入口的模型。团队管理员与数据驻留规则仍可能限制使用,目前不支持 UAE 推理驻留。不要因为没看到选项就反复重装。完整对照见 A8 模型选择。官方模型说明

输入框替你想下一句,但不会替你发送

Composer Predictions 会在回复结束后提供追问草稿。看到建议按 Tab 接受,检查文字、改好范围后自己发送;不喜欢就直接输入。最需要留意的是“修改”“发布”“删除”这类动作,别因为它替你写好了就顺手发出去。

这是个人 Pro、18 岁以上、支持地区的测试功能,适用于桌面端本地与 SSH 任务中的 Astra、6.1 Sol、6.1 Terra。开关和用量说明见 A6 输入预测。它基于本条对话生成建议,不会为了预测自行检索连接的 App 或记忆。官方使用说明

旧模型与加速档:这两处说法已经变了

  • GPT-5.5 已退役:ChatGPT 登录的 Codex 不再使用它;OpenAI API 和使用 API Key 的 Codex 会话不受此次调整影响。别漏掉定时任务和脚本里的旧型号。
  • 6.1 Sol 已有 Ultrafast:需要符合套餐、地区与工作区条件,不是所有人更新后都有。Ultra 是推理档,Ultrafast 是速度档;更快通常也更耗额度。

按 模型迁移清单 换型号,按 速度档说明 查资格。不要照九月历史记录判断今天是否可用。

桌面端小修复,出问题时很有用

10 月 8 日的 26.1007 修复了排队消息一直显示 Sending、第二个窗口里 Steer 不生效和 Changes 文件列表滚动问题。10 月 7 日的 26.1002 改善 Windows 更新后的沙盒刷新和 WSL Worktree 分叉路径冲突。遇到类似现象先检查桌面端版本,而不是升级 npm 包或关闭安全限制。修复记录见 官方桌面端日志。

手机:看进度、看额度,少来回切换

本周另有 Text your dot:通过 iMessage 或 Android RCS 联系 dot,目前只向美国 Pro 用户测试开放,需要审批时仍回 ChatGPT 核对。不是所有地区的用户都能添加这个入口,见 A9 适用范围与官方设置入口。

10 月 22 日 iOS 1.2026.286:支持的远程主机会在输入框上方显示后台命令入口,可以查看或停止命令;还可以 @ 提及其他已连接电脑上的任务。10 月 13 日的 1.2026.279 支持点开文件引用查看内容。具体步骤见 A9 手机查看与停止;这些 iOS 更新不能直接当作 Android 功能。

10 月 2 日的 iOS 1.2026.267 加入任务和额度小组件;10 月 7 日的 1.2026.272 加入 Page 内嵌预览和直接打开 Codex 任务链接,插件统一放在输入框加号菜单的 Plugins 里。它们改善的是查看和接力,不是让手机代替电脑执行本地任务。

  1. 先在手机更新 ChatGPT,打开 App,核对账号、工作区和已连接电脑。
  2. 想在主屏幕看进度,从 iOS 的添加小组件入口查找 ChatGPT 提供的任务组件;额度组件还可放在锁屏。实际名称和选项以当前系统为准。
  3. 组件支持选择电脑时,选中这次工作的那台。先点开一条熟悉的任务,核对标题与项目。
  4. 需要插件时,从输入框加号进入 Plugins。先读授权范围,只做一个查看资料的小测试。

小组件只适合扫一眼。涉及发布、发送或文件改动,打开完整任务核对结果;不要把状态卡片当成验收报告。手机显示电脑离线时,先恢复连接,不要重复新建同一任务。完整配对与排错放在 A9 手机使用步骤。来源:10 月 iOS 发布记录、Codex on mobile。

CLI 0.165.0:按原安装渠道更新

本轮核对的稳定版记录为 10 月 27 日的 0.165.0。用 npm 安装的人可以运行下面两行;用其他渠道安装就沿用原渠道,不要为了升级再装一份。只用 App 的读者不用额外安装 CLI。

terminal
npm install -g @openai/codex@0.165.0
codex --version

更新后先做只读小任务,确认能启动、能回复,再回到重要项目。命令速查见 附录 C。

终端日常操作:少改配置,少重复打字

新增操作你可以怎么用边界
/config（0.163）在会话中搜索设置,修改后看是否提示重启。不是所有选项都立即生效。
/presets（0.164）把常用提示词或斜杠命令存进 10 个编号位置。先保存只读检查类内容,不要把发布或删除命令当日常快捷操作。
/keymap（0.163）查看键位;默认前缀键 Ctrl+X 会展开操作菜单。以当前键位菜单为准,不照搬 App 的快捷键。
F9（0.163）语音中临时静音麦克风。F8 是切换语音会话,F9 不是结束任务或撤回操作。
工作中继续补一句（0.163）直接调整当前任务方向,例如“先停下改动,只列出问题”。打断不会撤销已经完成的文件或外部操作。
全屏看图片（0.164）在支持的终端里查看图片细节。需要 Kitty 或 Sixel 图像协议支持,普通终端不一定能显示。

0.165 还加入仓库筛选、关联 Worktree 的目录分组,并默认允许支持模型在对话中调整推理强度。入门练习见 CLI 第 03 章。版本依据:0.163–0.165 发布记录。

工具要重新登录,不用退出整条会话

CLI 0.161.0 支持在当前会话输入 /mcp login <name>。这里的 name 是已配置的 MCP 服务名,不是你自己的名字,也不是让你输入密码。先用 /mcp 看服务,再按实际名字登录。

例如配置中确实有一个叫 company-docs 的服务,就在 Codex 聊天输入框写 /mcp login company-docs。按提示在可信的授权页面完成登录,回到会话后先测试读取。登录成功不代表刚才失败的写入已经完成。详细步骤与桌面入口区别见 A7 MCP 登录。

语音没声音,先选对设备

新版 CLI 可以选择麦克风、扬声器和麦克风输入通道,选择保存在本机。输入 /voice settings 查看设置:输入选实际使用的麦克风,输出选耳机或扬声器;用外接声卡时再检查通道。它与“选择回答的声音”是不同设置。

先说一句“只复述这句话,不要操作文件”,确认收音和播放都正常。切换蓝牙耳机或拔插声卡后若没声音,重新检查设备和系统麦克风权限。桌面 App 的 Voice 设置不在这个终端命令里。见 CLI 操作小练习。以上两项依据:0.161.0 发布记录。

断线或卡住了,先确认上一步有没有完成

0.160 / 0.161 改善了断线队列、恢复历史、粘贴后发送和部分 Windows 启动问题,也增加了 SQLite 损坏的早期检测与备份保护。这些修复能减少干扰,但不保证任何外部操作都只执行一次。

  1. 恢复连接后,先看最后一条已完成回复、工具结果和待发送消息。
  2. 对已经发出的邮件、Git 提交或线上发布,到对应服务核对是否成功。
  3. 确认未完成后,只重试缺少的那一步,不要把整个任务再发一遍。
  4. 仍卡住时记录版本、报错和触发步骤,优先运行诊断;不要先删会话数据库。
恢复连接后先说这句
刚才连接断开了。请先只读核对最后一步是否完成,列出已有结果、未完成步骤和状态不明的操作。不要重复发送、提交、付款或部署;不确定的地方先问我。
先对齐实际状态,再继续工作。版本修复记录见下方官方来源。

进阶功能:知道边界就够了

Daybreak:新版默认规则已经调整

它面向获授权的安全工作,不是提速按钮,也不等于 Security 插件。早期 0.161 要手动开启的说明已被后续更新改变:0.163 起对符合资格的账号默认开启,服务器允许时也支持 API Key 的 exec 工作流。

普通用户保持默认即可。看不到入口先核对版本、账号资格、提供商和组织策略,不要为了“解锁”反复改开关。默认开启不等于所有用户都获得安全访问资格。依据:0.163.0 发布记录。

公司网关和 Bedrock,不要照抄个人账号配置

CLI 0.161.0 为 Bedrock 的兼容模型补充多智能体 V2 和 Ultra 支持。是否能用仍要看模型目录、AWS 区域和公司授权,不是每个模型都有每个档位。

0.165 新增内置 Google Cloud Vertex AI 提供商,配置名是 model_provider = "gcp";0.164 默认启用 Bedrock 配置向导。这是公司云服务接入,还要准备对应云账号、区域与授权,不是切换 ChatGPT 套餐。0.165 的 memory v2 默认开启仅指新配置档,不要据此推断旧账号记忆已自动导入或同步。

自定义模型网关则要兼容 Responses API,当前不支持只提供 Chat Completions 的地址或 wire_api = "chat"。能查到模型列表不代表工具、流式输出和后续对话都兼容。交给管理员先做一条只读测试,不要把密钥贴进公开问题帖。依据:Models、网关兼容要求。

Security 0.1.32:报告生成了,才算完成

本次插件日志最新列到 0.1.32,页面没有给这一版单列发布日期。它改进深度扫描的报告收尾、大结果分页和可恢复解析错误重试。看到“汇总完成”或一个 manifest 文件还不够,需要最终生成 report.md,再检查实际覆盖范围。

先做普通扫描确认范围,确实需要多轮检查时再做 Deep scan;后者会额外花时间和额度。操作与失败恢复见 A7 深度扫描。来源:插件日志、深度扫描说明。

升级前,花两分钟检查这几项

  • 模型:GPT-5.5 的 ChatGPT 登录退役已生效。按 A8 清单 检查默认模型、定时任务和脚本。
  • 凭据:登录信息可能保存在系统钥匙串,不一定有 auth.json。别因找不到文件就删除配置或重新搬运令牌。
  • 项目:保存重要改动,记清当前项目路径、分支和执行电脑;先做小测试再恢复长任务。
  • 插件:Security 插件目前列到 0.1.32,与 CLI 0.165.0 不是同一版本。插件、MCP 登录和系统审批分别检查。

出现问题可到 10 月可搜索排错,按报错关键词找对应处理办法。
