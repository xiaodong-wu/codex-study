面向零编程基础 · 桌面端 App + CLI 双路线

用说话的方式指挥 Codex
先看得见,再跑得深

这套教程现在分成两部分:一部分专门讲 Codex 桌面端 App,适合完全没有编程基础的人先上手;另一部分讲 Codex CLI,带你从终端、文件、GitHub、Vercel 一路走到上线产品官网。

先学桌面端 App → 进入 CLI 教程
2条学习路线 7章 App 教程 12章 CLI 教程 4个附录

先选哪条路线

如果你不确定,直接选左边。桌面端 App 更像一个可视化工作台,对新手更友好。CLI 更像一把轻巧的工具刀,适合你想理解底层流程时再学。

路线一 · 推荐先学

Codex 桌面端 App 教程

从安装、登录、打开项目开始,讲清项目、线程、Local/Worktree/Cloud、Review 面板、浏览器标注、Computer Use、自动化、技能、MCP、设置和安全边界。

  • 适合完全没有编程基础的人
  • 大量图文示意,先建立画面感
  • 重点是“怎么用 App 安全地让 Codex 干活”
从 App A0 开始 看功能总表
路线二 · 进阶实战

Codex CLI 教程

保留原来的终端路线:安装 Node.js 和 Codex CLI,学习口语化提示词,让 Codex 搭出产品官网,再用 GitHub + Vercel + 域名完成上线。

  • 适合愿意接触终端的人
  • 更接近开发者真实工作流
  • 重点是“从 0 到 1 上线一个产品官网”
